# Changelog

This file records significant changes to the canonical form of *The Simulation Order*.

It exists to preserve a clear record of what changed, why the change was made, and who approved it.

Routine corrections to spelling, punctuation, formatting, broken links and file names do not normally require an entry here. Changes to the fundamental texts, core ideas, doctrine or canonical structure must be documented.

The Finnish edition remains the original source of the work. Changes to the canonical work follow the approval process defined in [CONTRIBUTING.md](CONTRIBUTING.md).
