# Original Finnish Edition

This directory contains the original Finnish edition of **The Simulation Order** (*Simulaation Järjestys*).

Finnish is the original language of this work. This edition serves as the canonical source from which translations are made.

The Markdown files preserve the contents of **The Holy Collection v14**. Page layout, cover pages, page numbers, and printed formatting belong to the master document and are not reproduced in these Markdown files.

## Canonical Status

This directory contains the canonical version of The Simulation Order.

The original language of the work is Finnish.

Translations, forks, and derived works are welcome under the project's license, but they do not become the canonical work.

The canonical text changes only through the process defined in CONTRIBUTING.md and recorded in CHANGELOG.md.
