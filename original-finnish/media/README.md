# Finnish Media

This directory contains the poster artwork and source files for the original Finnish edition of **The Simulation Order** (*Simulaation Järjestys*).

## Posters

- [A3 poster — Finnish, 300 dpi (PNG)](THE_SIMULATION_ORDER_Poster_A3_FI_300dpi.png)
- [A4 poster — Finnish, 300 dpi (PNG)](THE_SIMULATION_ORDER_Poster_A4_FI_300dpi.png)

## Source files

- [Poster source files and background assets (ZIP)](Poster_Sourcecodes_and_BG.zip)

The source archive contains the editable HTML layouts and image assets used to assemble the posters. Use these files as the starting point for creating translated poster editions. Update the text and any language-specific details, then export the finished poster at the required print size and resolution.

Please preserve attribution and comply with the project's [CC BY-SA 4.0 license](../../../LICENSE.md) when adapting or redistributing these materials. Translated editions should be placed in the corresponding language edition's own `media/` directory.

## Notes

The A4 poster's current filename contains `AA` rather than `A4`; the link above intentionally uses the filename that exists in this repository.
