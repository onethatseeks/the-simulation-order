# English Edition

This directory contains the English edition of **The Simulation Order**.

The English edition is a translation of the original Finnish edition (*Simulaation Järjestys*). It is intended to serve as the primary international working edition of the project.

The files translate the Markdown files of the [Original Finnish Edition](../original-finnish/), which preserve the contents of **The Holy Collection v14**. Page layout, cover pages, page numbers, and printed formatting belong to the master document and are not reproduced.

Terms are translated according to the [terminology reference](../TERMINOLOGY.md).

**Source version:** the Finnish original as of release `v1.0` *(to be confirmed when the release is published)*.

## Canonical Status

The Finnish edition is the canonical source of the work. This English edition is a translation and does not replace it. If the English text and the Finnish original differ, the Finnish original takes precedence.

Translation problems, unclear terms, and suspected errors should be reported through an issue, as described in [CONTRIBUTING.md](../CONTRIBUTING.md).
